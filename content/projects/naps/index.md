NAPS introduces a neural aggregation module for variable sensor configurations in physiological signal modeling.

The project focuses on automatic sleep staging from polysomnography using frozen pretrained unimodal encoders and adaptive multimodal aggregation, with attention-based fusion designed for heterogeneous physiological input.
