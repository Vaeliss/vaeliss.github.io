About

I am a PhD candidate in Informatics at USI working on machine learning for physiological and health data, with sleep as the main application domain.

My research studies machine learning models under real-world heterogeneity: subject variability, device differences, dataset shifts, multimodal sensing constraints, and noisy labels. The broader goal is to build health AI systems that can be evaluated fairly and applied beyond the research prototype stage.

I am interested in R&D roles around wearable sensing, physiological time series, reliable generalization, multimodal modeling, and research-to-code execution.

Open-source sleep staging toolkit

SLEEPYLAND

SLEEPYLAND is an open-source, open-weight toolkit for fair evaluation and local use of automatic sleep-staging models. It packages state-of-the-art algorithms and trained weights behind a zero-code web GUI, so users can run zero-shot sleep staging locally and inspect hypnograms, hypnodensities, metrics, and confusion matrices without writing code.

  • Open source. Dockerized services, notebooks, GUI, data harmonization, and evaluation code are available on GitHub.
  • Open weights. The repository includes trained model weights across U-Sleep, DeepResNet, and SleepTransformer variants.
  • Local GUI. Users can launch a browser interface at localhost and keep EDF/PSG data on their own machine.
  • Zero-shot results. The workflow supports prediction/evaluation with visual hypnograms, hypnodensities, and performance summaries.
